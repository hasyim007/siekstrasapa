KPI Berbasis AI (Cloudflare Workers AI)

Fitur KPI & kesimpulan otomatis di menu Dashboard Analitik berjalan langsung lewat Cloudflare Workers AI yang sudah tersambung ke Worker ini. Tidak perlu API Key apa pun -- cukup pastikan binding AI sudah aktif (lihat PANDUAN-DEPLOY-CLOUDFLARE.md).

Backup & Restore Data

Backup mengunduh seluruh data sistem (kelas, ekskul, siswa, survei, usulan, galeri, pengaturan) sebagai satu file JSON yang bisa disimpan sebagai cadangan. Restore memulihkan data dari file backup tersebut.

Backup Data

Unduh salinan seluruh data saat ini ke perangkat Anda.

Restore Data

Menimpa seluruh data saat ini dengan isi file backup. Tindakan ini tidak bisa dibatalkan.
